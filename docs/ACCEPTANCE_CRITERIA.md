# Acceptance Criteria — Pedestrian Pursuit MVP

The MVP is accepted when all of the following are true:

## Repository

- [x] Repo can be cloned and opened in Godot 4.x
- [x] Game launches without errors
- [x] README explains setup, controls, and prototype status
- [x] Docs cover vision, MVP scope, architecture, and roadmap

## Race Loop

- [x] Player can start a race from main menu
- [x] Player can complete 3 laps
- [x] Lap count increments correctly
- [x] Checkpoints prevent invalid lap skipping
- [x] Countdown (3, 2, 1, GO) with start boost timing
- [x] Results screen appears after finish

## Movement

- [x] Sprint (manual acceleration)
- [x] Steer left/right
- [x] Jump
- [x] Slide/stomp (ground and air)
- [x] Foot drift with release boost
- [x] Boost meter consumption (Q)
- [x] Simple trick input while airborne

## Track

- [x] Sneaker City Sprintway closed loop
- [x] At least one drift curve
- [x] Speed lane section
- [x] Slow terrain section
- [x] Bounce pad or ramp
- [x] Item box area
- [x] One shortcut route

## Items

- [x] Collect item from item box
- [x] Use Turbo Toes (speed burst)
- [x] Use Lace Trap (hazard behind player)
- [x] Use Sole Shield (block one hit)

## AI

- [x] At least one AI racer follows track and finishes

## HUD

- [x] Lap counter
- [x] Position display
- [x] Boost meter
- [x] Held item display
- [x] Race timer
- [x] Speed or speed state
