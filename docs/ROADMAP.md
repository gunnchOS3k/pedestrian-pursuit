# Roadmap — Pedestrian Pursuit

## Milestone 1 — Repository Bootstrap ✅

Git repo, Godot project, README, LICENSE, docs, folder structure. Project launches to main menu.

## Milestone 2 — Player Movement Prototype ✅

Player racer, third-person camera, accelerate, steer, jump, slide/stomp, speed tuning.

## Milestone 3 — Racing Loop ✅

Test track loop, start/finish, checkpoints, lap counting, countdown, timer, finish state.

## Milestone 4 — Drift and Boost ✅

Drift input, charge, release boost, boost meter, pickups, consumption.

## Milestone 5 — Track Features ✅

Speed lane, slow terrain, bounce pad, shortcut, barriers.

## Milestone 6 — Items ✅

Item box, Turbo Toes, Lace Trap, Sole Shield, item HUD.

## Milestone 7 — AI Racer ✅

AI path following, lap/checkpoint interaction, position tracking.

## Milestone 8 — Polish and Documentation ✅

UI polish, debug overlay, tuned variables, updated docs.

## Future Milestones

- Character and shoe select screens
- 3 AI racers with difficulty tiers
- Trick scoring and stumble penalties
- Time trial with ghost replay
- Local multiplayer prototype
- Second track (Schoolyard Speedway)
- Wall-kick and rail grinding
- Accessibility options (auto-accelerate, remapping)
- Audio pass (footsteps, drift sparks, countdown)
- Save/load settings
- Mobile touch controls
