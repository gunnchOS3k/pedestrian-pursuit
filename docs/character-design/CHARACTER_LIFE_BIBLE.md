# Character Life Bible — Pedestrian Pursuit

Original runners. No brand logos. No licensed characters.

**Audit baseline (main `d0b659e`):** one named profile (Dash) + three anonymous palette AI clones; single procedural gait; no stumble/podium body language.

Launch roster expands to eight original runners.
