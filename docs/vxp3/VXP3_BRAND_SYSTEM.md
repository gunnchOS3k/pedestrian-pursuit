# VXP-3 Brand System

## Name
- Product: Pedestrian Pursuit
- Internal art direction: KINETIC SOLE

## Concept
Footwear is the machine. The runner is the vehicle. Energetic, athletic, tactile, fast, playful, competitive, readable, stylish, optimistic, original, accessible.

## Color roles (not equal usage)
| Role | Token | Use |
|------|-------|-----|
| Night Track | `#0B1220` | Primary background |
| Asphalt | `#1A2336` | Secondary surface |
| Panel | `#243049` | Cards / panels |
| Kinetic Orange | `#FF6A3D` | Primary CTA |
| Pursuit Blue | `#3D8BFF` | Navigation / secondary |
| Midsole Yellow | `#F5C518` | Perfect Step / podium 1 / highlights |
| Boost Cyan | `#2EE6D6` | Boost meter / timer |
| Grip Green | `#3DDC84` | Grip / safe |
| Hazard Red | `#FF4D6A` | Wrong-way / hazard |
| Ghost Violet | `#A78BFA` | Ghost / bounce accent |

## Footwear symbols (non-color)
- Grip: tread bars
- Speed: forward chevron
- Bounce: arc + ball
