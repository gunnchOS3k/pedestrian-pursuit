# Item counterplay (Wave E Alpha)

| Item | Warning | Primary counters |
| --- | --- | --- |
| Turbo Toes | none (self) | Corner brake / draft break after overshoot |
| Lace Trap | brief lace flash | Sole Shield, Bounce Bubble, jump, slide |
| Sole Shield | none | — (defensive) |
| Pulse Horn | ~0.85s forward pulse warn | Sole Shield, slide, break draft cone |
| Magnet Lace | ~1.1s shimmer toward leader | Sole Shield, Bounce Bubble, wall-kick |
| Bounce Bubble | none | Reflects one hazard + hop |

HUD flashes `WARN: …` when warning items fire so counterplay is readable in Alpha playtests.
