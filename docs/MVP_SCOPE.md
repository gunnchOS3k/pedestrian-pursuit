# MVP Scope — Pedestrian Pursuit: Sole Rush Prototype

## Gameplay

- [x] One playable racer (Dash, Balanced class)
- [x] Three shoe presets (Starter Soles, Speed Sneakers, Grip Soles)
- [x] One complete test track (Sneaker City Sprintway)
- [x] Manual acceleration, steering, jump, slide/stomp
- [x] Foot drift with at least one boost level
- [x] Boost meter with consumption and pickups
- [x] Item boxes with three items (Turbo Toes, Lace Trap, Sole Shield)
- [x] 3-lap race with checkpoint validation
- [x] Race countdown with Perfect Step at start
- [x] Race timer and results screen
- [x] Basic AI racer (1)

## Track Features

- [x] Closed loop with start/finish line
- [x] Drift curve section
- [x] Speed lane
- [x] Slow terrain patch
- [x] Bounce pad / ramp
- [x] Item box area
- [x] One shortcut route
- [x] Basic barriers/walls

## UI

- [x] Main menu
- [x] Race HUD (lap, position, boost, item, timer, speed)
- [x] Countdown display
- [x] Pause menu
- [x] Results screen
- [x] Settings placeholder

## Out of Scope (Stretch Goals)

- 3 AI racers
- Character/shoe select menus
- Time trial ghost
- Local multiplayer
- Second track
- Final art and audio
- Wall-kick and rail grinding
