# Controls — Pedestrian Pursuit

## Keyboard

| Action | Key |
|---|---|
| Move/Steer | A/D or Left/Right |
| Accelerate | W or Up |
| Brake/Reverse | S or Down |
| Jump | Space |
| Drift | Shift |
| Slide/Stomp | Ctrl |
| Use Item | E |
| Boost | Q |
| Special Ability | R |
| Pause | Esc |
| Debug Overlay | F3 |

## Controller (mapped in InputManager)

| Action | Control |
|---|---|
| Steer | Left Stick |
| Accelerate | Right Trigger |
| Brake | Left Trigger |
| Drift | Left Bumper |
| Jump | A / Cross |
| Slide/Stomp | B / Circle |
| Use Item | X / Square |
| Boost | Right Bumper |
| Special | Y / Triangle |
| Pause | Start / Menu |

## Mobile (Future)

Swipe left/right to steer, tap to jump, hold and drag to drift, swipe down to slide/stomp.
