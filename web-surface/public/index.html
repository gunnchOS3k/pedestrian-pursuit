What is this?

Arcade foot-racing game. This staging Worker loads a development Godot web export through an R2 binding. The wasm file is not a Worker static asset.

Why does it exist?

It gives this repository a public web surface and a development boot path. The oversized wasm and pck stay in R2, outside the Worker static-asset limit.
