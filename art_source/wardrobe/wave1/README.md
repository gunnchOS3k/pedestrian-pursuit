# Kinetic Sole garment atelier — first six outerwear candidates

Editable native mesh source: `scripts/art/GarmentAtelier.gd`. Six explicit existing catalog IDs only; other items return false and preserve the original fallback. No catalog, outfit selection, body mesh, stat, collider, character canon or clothing from another agent is replaced. Exact primary/accent colors are read from the selected garment record. New geometry and manufacturing details are original interpretations, not regional or historical costume claims.

`static attach(visual: Node3D, g: Dictionary, hs: float, ws: float) -> bool` is intended for the start of the existing `RacerVisual._attach_garment_mesh` method. Return immediately from that caller only when it returns true. No hook has been added by this source author. LOD2, unsupported IDs, invalid proportions or a missing torso return false.

The torso shell derives width, depth, height and center from the actual torso mesh AABB. Fitted rows create open-front, hollow neck/hem panels, with distinct collars, lapels, yokes, split mantle panels and physical pocket fronts rather than a common capsule recolor. The native source batches geometry by material into one torso mesh. Two additional sleeve meshes derive their length/radius from the existing arm limb bounds and attach under the shoulder pivots. All pieces inherit existing movement. They add no timers, random animation, networking or persistent state. Rebuilding the existing visual frees their parent hierarchies; repeated attachment of the same garment is idempotent.

The six designs are Metro Pulse's open zip windshell/dropped tail; Harbor's drape coat/rolled cuffs/sash/patch pockets; Neon's cropped yoke/panel jacket; Midnight's notched lapel/tails/button coat; Orbit's shoulder mantle/six separate cape panels; Archive's V-neck/placket/ribbed cardigan. Body fronts remain open so selected underlayers stay visible. No other garment is hidden or removed. Sleeves are separate rigid pieces following existing shoulder pivots, not new skinned cloth or elbow deformation. Decorative zips/buttons/pockets do not supply garment interaction.
